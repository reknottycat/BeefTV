## 实际界面与保存链路

在真实 `/dev/director-repro` 工作台中完成候选预览与应用、观看意图、准确内容、动作、连续状态、参考引用、声音 cue、整条检查及制作包生成。关闭并重开工作台保留编辑；修改时长后撤销、重做恢复相应状态。未完成的 `key=value` 输入显示字段错误并阻止导出，没有写入无效方向状态。

时长或 fps 变化会使旧 QA 与旧导出链接失效。锚定主事件的 cue 在当前镜头重编译；实际界面从 24fps 切到 30fps 后，7 秒镜的主事件为第 113 帧。明、暗主题均完成实际界面观察。播放后可暂停并显示当前帧。浏览器采集的 error 日志为空。

“应用到镜头”实际返回当前合成画面的 1280×720 PNG，页面本地回调显示收到的图片。方向镜头的截图和封面走同一 SVG 求帧器；截图期间若场景或镜头已变更，拒绝回写旧画面。原有三维视口继续保留。

界面提供有文件名的可见 JSON 下载链接。验证读取了该链接的完整 data payload 并保存；渲染器消费的输入与直接保存的 DOM payload 逐字节一致，Scene / Timeline 的 SHA-256 也相同。内嵌浏览器的原生 download event 未成功，因此这条证据证明实际内容交接，不声称浏览器原生下载已验证。

该 DEV 页面使用实际组件及保存协调器，但保存和图片回写是本页的本地回调。真实画布复制与保存失败后的草稿恢复另外通过现有 store / coordinator 的自动化测试验证；本次没有运行原生桌面或真实项目后台持久化验收。

## Rendered patterns

下列六个模式已由真实 Remotion 消费制作包并输出 MP4，因此目录状态为 `runtime_verified`。这一状态限于记录中的样片参数与运行条件。

| 模式 | 实际消费与检查 |
| --- | --- |
| Object Relay / 对象交接 | 独立小样及界面制作包；接收端回稳与主事件 cue |
| Camera Push / 镜头聚焦 | 独立小样；主体与摄影机错开启动，含安全区检查 |
| Kinetic Type / 语义文字 | 独立小样；文字依次完成、回稳及阅读停留 |

| Impact Reveal / 冲击揭示 | 独立小样；冲击事件与音效共用 Timeline |
| Continuous Shape Transition / 形状连续转场 | 独立小样及真正两镜样例；编译器继承同一元素的上一镜出口 |

其余模式保留 `catalogued`，没有宣称具有执行器。参考上游快照及本地注释分别保存，刷新不覆盖注释；实际审看过的参考仅标记静帧审看。来源与刷新规程见 [motion-reference-sources.md](motion-reference-sources.md)。

## 样片、接缝与局部返修

本地 `review.html` 包含六模式小样、21.6 秒 MOPD 原声片段、12 秒三镜灰模连续动作、8 秒两镜共享形状及7秒实际 UI 交接样片；同位置的原版 MOPD 片段也保留。总数量、实际帧数与编码规格以运行摘要为准。所有当前样片完成整段 AV 解码及全帧数值扫描，没有检测到整帧黑屏；指定编码帧经过模型静帧审看。

Remotion 与界面调用同一 `evaluateDirectorMotion()` / SVG 实现，渲染前从 Scene 重编译并检查制作包 Timeline。实际使用 Remotion 4.0.518、两路并发、`h264_nvenc`；布局使用 Chromium SwiftShader。早期八条样片的实际渲染时源码哈希被保留，新增可选 cue anchor 后再次编译确认原显式 cue 的 Timeline 未变；后两条直接消费最终核心。运行摘要分别记录这些代码组，没有用最终哈希替换旧渲染事实。

局部返修保留实际旧参数和旧结果：短镜阅读停留不足时，把 `motion.settleFrames` 从 12 改为 8，保留 30 帧阅读门槛，再渲染受影响样片。抽帧发现的标签碰撞、倒置文字、连线穿字和灰模手臂跳变也已修正。所有当前制作包的 Frame Critic 结果为零 issues，这只是确定性检查结论。

三镜灰模呈现拿起草稿、教师递出、学生接住并放回桌面。最终编码的两个接缝帧，白色草稿中心位移均为 0 像素；手臂接触和释放前后帧另行保留。它验证可见动作与持物连续性，没有验证真人身份或生成视频的角色一致性。

两镜共享形状的首镜出口与次镜入口在位置、宽高、旋转、标签上相等。最终编码接缝帧的形状像素边界相同；椭圆有旋转对称性，旋转数值另外从共享状态核对。首次夹具浅拷贝错误保留在旧 v1.0.0 样片；修订 v1.0.1 使用独立深拷贝及明确出口断言后重渲染。

UI 交接样片验证了第 113 帧 cue 的实际 PCM 起点及最终 AAC 波形位置；精确测量在运行摘要的 `uiHandoff` 下。音频编码会改变波形，不把单样本峰值测量当成听感结论。
