# 画布时间线预览

在画布视频节点打开时间线编辑弹窗后，点击预览区播放。播放头使用时间线时钟，空白区间按原时长经过；即使当前位置没有视频，也可以播放或暂停。播放到时间线末尾自动停止，再次播放从开头开始。关闭弹窗停止预览。

视频定位包含素材内裁剪起点，并以素材总时长限制位置；时间线播放头驱动素材定位，素材自身的时间更新不会跳过空白区间。直连素材优先于画布节点。预览呈现视频、图片、字幕和独立音频，尊重轨道可见性、静音、音量与淡入淡出。

已保存为资源的素材使用本地时间线渲染：裁剪、空隙、独立音轨混音和字幕烧录统一执行，实际封装及时长核验后才报告成功。字幕烧录失败不再静默导出无字幕替代片。文字装饰与重叠画面不支持本期连续剪辑，必须先调整；预览和机器检查不能替代人物连续性审看或混音试听。使用入口和能力边界见 [自动制作](content/docs/overview/automatic-production.mdx)。

播放层选择和源内时间换算复用了 Nomi 的 Apache 历史代码，具体提交、修改和许可见 [第三方声明](../THIRD_PARTY_NOTICES.md)。
