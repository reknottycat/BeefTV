# 本地生成界面合同

此界面属于用户新增的 ComfyUI 生成适配。已有 `DESIGN.md` 的第一期只读资产目录合同继续保留；其第一期禁止生成操作的边界不用于替代本轮已授权功能。第一期目录页面的完成和验收状态保持原记录。

`/local-comfy` 沿用 BeefTV 的 WorkspacePage、PageHeader、Ant 控件、语义 token 和原工作区布局。画布图片/视频镜头提供“本地生成”链接；项目、节点、镜头 ID 用路由传递，提示词和参考资产 ID 用页面状态传递，私有文字与媒体地址不进入 URL。原剧本编辑、角色/场景/道具库、导演台和云渠道保留。

界面区分独立适配台账、生成结果归档、上游资产登记和上游画布保存。它们分别成功才显示对应完成信息。生成开关关闭时，提交与重做不可用；提交结果未知时，只查询原记录，不能重做。停止等待不取消已提交的 GPU 作业。

参考图使用有序资产选择；配方没有参考槽时拒绝图像输入，缺少所需槽时阻止提交。结果保留原始画幅并显示任务状态、错误、版本记录和归档入口。关联原画布是显式操作，保留原导演镜头、追加确定 ID 的结果节点、资产关联与血缘，重复关联复用相同生成效果。

Spark 的构建设置 `VITE_CANVAS_LOCAL_RESOURCE_STORE=backend`，素材由同源 Go 资源服务持久化。该设置下上传失败必须报错；浏览器缓存不能表示 Spark 保存成功。上游默认浏览器本地存储行为继续保留。画布关联还必须完成服务器快照同步。

已读取 12ui 设计技能；其 hosted 候选/改进流程需要额外云服务授权，本轮没有执行。完整类型检查、构建和浏览器视觉验收依赖已安装的锁定前端依赖。纯逻辑测试、语法解析或代码审阅不替代这些验证；实际交付报告分别记录执行结果。
