# 自动制作

侧栏「自动制作」打开 `/production`。新建制作记录时可以沿用已有画布项目；制作历史可恢复方案、镜头状态、时间线和历史成片。

输入作品要求并选择可用导演模型，系统使用现有 CreationRun 规划合同整理需求和方案。补充必要问题、确认方案后，镜头按真实依赖顺序制作并保存到项目；全部镜头就绪后自动编排视频、检查并导出。模型不可用时明确提示配置入口，也可以从素材库加入已有视频、图片、配音和音乐完成本地剪辑。

## 制作工具

展开「制作工具」可查看系统模型、DGX / ComfyUI 原生配方和已保存的 RunningHub 工作流。导演获得同一份能力快照：完整工具标识、图片/视频用途、可验证规格、执行状态与阻塞原因。规划文本仍使用系统受管导演模型；镜头按各自选择的工具执行，可在同一作品中混用通道。

DGX 配方通过同源适配器实时读取。当前原生集成支持 Qwen-Image-2.1 的 1024 与 512 文生图配方，以及 H3 I2V Turbo 4 步：864×480、124 帧 / 24 fps，需要一张符合配方要求的 PNG 首帧。生成开关关闭时可以核对已登记参数，但不能提交生成。

RunningHub 连接与条目编辑入口为 `/settings?section=runninghub`。模型目录位于 `/settings?section=channels`，可按来源和用途筛选；自动制作页提供直接链接。

RunningHub 从连接设置中已保存的 Workflow / App 读取参数，使用稳定的 `runninghub:<kind>:<id>` 标识。连接、积分 API Key、插件与参数齐备后，通过现有任务中心提交和恢复。工作流视频时长与比例只取自其参数，不借用普通视频模型默认值。当前本地工作区不支持向 RunningHub 上传参考素材，需参考图的条目明确显示待配置；无需参考素材的图片/视频条目可以进入此制作链路。

工具与模型目录保留图片、视频、音频和 3D 的发现信息；目录收录不代表账户权限或当前可执行。自动制作的生成项目前支持图片/视频，已有音频仍可加入时间线；音频生成、3D 生成和 3D 渲染未接入本链路。

工具执行仍遵守获批方案、当前账号资源归属、插件状态与生成开关。准备阶段只校验，不创建供应商任务；批准执行后持久化统一任务。连接凭证只进入加密执行快照，不写入方案、会话或返回给导演。相同执行项重复提交返回原任务。

## 声音与剪辑

画面依时间线起点排列，空隙和片尾按总时长补黑场。可调整片段起点、展示时长、源内裁剪起点和音量；独立声音使用自己的时间线位置。预览支持视频、图片、字幕及独立音轨，遵守轨道可见性、静音和片段淡入淡出。音量 0 保持静音。

自动制作页的时间线保存在制作运行中，镜头与素材仍引用已有项目资源。进入导演台可以编辑项目镜头；镜头重做后，重新编排时间线再导出，避免把旧镜头误作新版本。既有画布时间线弹窗也复用本地成片渲染；素材尚未保存为资源时，声音或轨道效果导出会明确要求先保存。

## 检查、导出与恢复

导出前检查有效资源引用、非负起点、正时长、源内裁剪范围、画面重叠与总时长。当前合成采用连续剪辑，重叠画面需要先调整；文字装饰须改为字幕或画面素材。

本地 FFmpeg 合成 1920×1080、30fps MP4，保留视频原音并混入独立音轨。自动制作页提供独立 SRT；画布时间线导出请求烧录字幕，失败会显示错误。产物通过实际媒体封装、画面流、音轨与时长核验后才写入资源并报告成功。人物连续性、内容质量与混音听感仍由用户预览检查。

导出意图先持久化，再创建任务。断线恢复使用原请求标识与原时间线快照，返回同一任务；同一标识用于不同快照会报冲突。先核对未知提交，确认任务失败或取消后才可重新编辑。已完成成片列入历史，重新编辑不删除旧成片。

「重做此镜」使用既有镜头重做合同，执行中镜头不能重复提交，其他镜头与历史产物保留。暂停、页面关闭或连接中断不把未完成的媒体标为成功。

## 运行依赖

使用本机 `ffmpeg` 与 `ffprobe`。可以用 `CANVAS_FFMPEG_PATH` 指定 FFmpeg；优先从同目录查找 FFprobe，随后查找系统路径。字幕烧录需要该 FFmpeg 含 `subtitles` 滤镜。缺少工具、素材不可读取、合成失败或产物检查失败均进入明确失败态。

模型生成沿用现有模型配置与开关。自动制作页没有另外启动 OpenDirector 服务，不新增独立的模型执行器或素材库。旧 `/agent/*` 路由与退场任务继续保持关闭。

## 渲染 API

`POST /api/timeline/renders` 接受 `projectId`、`timeline`（v2）、可选 `clientKey` 与 `burnSubtitles`，返回统一任务。`clientKey` 最长 128 字节，在当前工作区用户范围内标识一次固定渲染；任务中心查询状态与 `resultJson`。结果包含 `resourceId`、`fileName`、`size`、`durationMs`，有字幕时另附 `subtitleSrt`。

播放定位复用的 Nomi 历史模块与 Apache 许可见仓库 `THIRD_PARTY_NOTICES.md`。当前 Nomi 新版交互未直接复制到本工程。
